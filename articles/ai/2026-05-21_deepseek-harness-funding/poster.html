要点速览
DeepSeek 从“不融资”转向“融对资”：首轮募资 500 亿元、估值 3500 亿元，同时组建 Harness 团队对标 Claude Code，从模型公司向 Agent 公司 转型，商业天花板从 API 切换到 SaaS。
3
深度解读
三座大山倒逼转型
算力瓶颈、人才争夺、产品化缺失，让“不融资”模式难以为继。外部资本与期权池，成为规模化扩张的前提。
Harness 是战略信号
组建 Harness 团队对标 Claude Code，意味着 DeepSeek 从只做基座模型，转向把模型装进产品、直接解决用户问题。核心公式是 Model + Harness = Agent。
融对资的底层逻辑
创始人自掏 200 亿、只收战略与长期资本、融资前锁死股权，这套打法近似量化基金的管理逻辑——拿钱，但不被钱绑架。

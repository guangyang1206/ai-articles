# Claude Opus 5 发布：能力逼近 Fable 5，价格一分不涨

- **选题日期**：2026-07-24（Anthropic 发布 Claude Opus 5）
- **类型**：次条 · 产品分析

- **目标受众**：AI 创业者 / 算法工程师 / 科技投资人 / 产品经理

## 选题理由

1. Claude Opus 5 是 Anthropic 在 GPT-5.6 上线（7-9）之后两周的正面回应，两家旗舰模型的"前后脚"竞争，是 7 月大模型战局的高潮。
2. 定价策略极有看点：性能接近旗舰 Fable 5（价格的一半），但维持 Opus 4.8 的原价——"加量不加价"的性价比打法。
3. 与第二篇（GPT-5.6 三档降价）形成天然对照，揭示两家公司在"性价比战争"中的不同策略。

## 核心信息（事实链，已多源交叉核实）

- **发布时间**：2026-07-24，全平台同步上线。
- **定位**：新一代 Opus 层级旗舰，"多领域能力接近 Fable 5，价格仅为一半"。
- **定价**：与 Opus 4.8 完全持平——输入 $5/百万 token，输出 $25/百万 token。
- **产品线背景**：Anthropic 2026 年 5-6 月密集更新（Opus 4.8 于 5-28 发布、Fable 5 于 6-9 发布），Opus 5 是这条线的又一迭代。
- **竞争背景**：GPT-5.6（7-9 上线）之后两周，正面回应。

## ⚠️ 数据口径风险（写作与审核需处理）

| 数据点 | 风险 | 处理方式 |
